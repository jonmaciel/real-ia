Nova UX explicitamente solicitada pelo usuário:
Em /buscar, há um input e UMA lista principal. Cada prompt enviado atualiza essa
lista automaticamente, sem segunda lista de recomendações e sem clique extra
para aplicar os critérios. O campo mostra Atualizando… / Lista atualizada.
Quando necessário, também mostra a pergunta do backend, como comprar ou alugar.

redirecionar automaticamente o usuário da home ou de um detalhe.
